# 偶像周邊預購結帳 MVP（課堂作業）

這是一個「只收集金流相關資料、不串接真實金流」的最小可行產品（MVP）。
情境為偶像周邊預購，粉絲自製示範頁面，商品皆為虛構，不會真的扣款。

## 功能
- 選擇商品版本與數量（+／− 按鈕），每項商品有限購上限
- 即時計算小計、運費與應付總額
- 填寫購買人資料，並逐欄檢查格式（錯誤欄位會標紅並說明原因）
- 選擇取貨方式（超商取貨／宅配）與付款方式（信用卡、超商代碼、ATM 轉帳、LINE Pay，皆為模擬）
- 送出後產生訂單編號，並顯示收集到的訂單、購買人、取貨與付款資料（JSON）

## 資料與隱私
- 信用卡欄位僅供示範，請勿輸入真實卡號；系統只保留末四碼，其餘立即丟棄
- 資料只存在瀏覽器畫面中，不會上傳到任何伺服器
- 粉絲族群包含未成年人，所以只收訂單必要的資料，暱稱為選填

## 使用方式
直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西。

## 技術
純 HTML、CSS、JavaScript，單一檔案。
